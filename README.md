# Portfolio · Marcos Griffa

Portfolio web personal con diseño moderno, fondo animado y enfoque en proyectos de análisis de datos y automatización.

## Sobre el proyecto

Soy estudiante de **Lic. en Ciencia de Datos** en la Universidad de Buenos Aires (UBA) y desarrollo soluciones que combinan análisis de datos, automatización de procesos e inteligencia artificial.

Este portfolio fue construido desde cero para mostrar mi trabajo de forma clara y profesional, destacando:

- Proyectos end-to-end en Python, SQL y n8n.
- Experiencia laboral en control de operaciones y gestión.
- Skills técnicas en Data Science y automatización con IA.

## Stack técnico

| Tecnología | Uso |
|------------|-----|
| **React 18** | Framework de UI |
| **Vite** | Build tool y servidor de desarrollo |
| **Tailwind CSS** | Sistema de estilos utility-first |
| **Lucide React** | Librería de íconos |
| **Fraunces · Inter · JetBrains Mono** | Tipografías (Google Fonts) |

---

## Características del diseño

- 🌑 **Modo oscuro nativo** con paleta lima y ámbar
- 🌊 **Auroras animadas** de fondo en movimiento constante
- ✨ **Spotlight interactivo** que sigue el cursor del mouse
- 🎯 **Objetos geométricos con parallax** que se desplazan al hacer scroll
- 📐 **Grid sutil** con máscara radial
- 🎨 **Tipografía editorial** con detalles tipo "terminal"
- 📱 **Diseño responsivo** adaptado a mobile y desktop

## Cómo correrlo localmente

Si querés clonar el repo y verlo funcionando en tu máquina:

```bash
# 1. Cloná el repositorio
git clone https://github.com/MarcosGriffa/portfolio-griffa.git

# 2. Entrá a la carpeta
cd portfolio-griffa

# 3. Instalá las dependencias
npm install

# 4. Levantá el servidor de desarrollo
npm run dev
```

Después abrí tu navegador en `http://localhost:5173/`.
